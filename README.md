# بوابة المبيعات — مشاريع الشركة

موقع خفيف (حاسوب + هاتف) يفتح منه فريق المبيعات المشاريع ويرسلون ملفاتها للعملاء عبر واتساب. البيانات في **Google Drive**.
بدون أي اعتماديات: يلزمك فقط **Node.js 20.12 أو أحدث**.

## 1) تجهيز Google Drive

1. أنشئ مجلداً رئيسياً في Drive (مثلاً «المشاريع») وانسخ معرّفه من الرابط: `drive.google.com/drive/folders/`**`هذا_هو_المعرّف`**
2. داخل Google Cloud Console ([console.cloud.google.com](https://console.cloud.google.com)):
   - أنشئ مشروعاً ← **APIs & Services ← Library ← Google Drive API ← Enable**
   - **OAuth consent screen**: النوع External، أضف بريدك، ثم اضغط **Publish app** (كي لا ينتهي الرمز بعد 7 أيام).
   - **Credentials ← Create credentials ← OAuth client ID ← Desktop app**. انسخ Client ID و Client Secret.
3. انسخ `.env.example` إلى `.env` واملأ: `DRIVE_ROOT_FOLDER_ID` و `GOOGLE_CLIENT_ID` و `GOOGLE_CLIENT_SECRET`.
4. على حاسوبك شغّل `npm run drive-auth`، افتح الرابط، سجّل الدخول بحساب Google صاحب المجلد (وافق رغم تحذير «تطبيق غير موثّق»)، ثم انسخ السطر `GOOGLE_REFRESH_TOKEN=...` إلى `.env`.

> بديل: Service Account مع Shared Drive في Google Workspace — راجع آخر `.env.example`. مع حساب Gmail عادي استخدم الطريقة أعلاه، لأن Service Account لا يستطيع رفع ملفات إلى Drive شخصي.

## 2) التشغيل

```
cp .env.example .env     # ثم عدّله
node server.js
```
يطبع التطبيق حساب المسؤول عند أول تشغيل (`ADMIN_USERNAME` / `ADMIN_PASSWORD`). بدون إعداد Drive يعمل بتخزين محلي للتجربة.

**الاستضافة**: أي خادم يشغّل Node (VPS أو Render أو Railway أو Docker بالـ `Dockerfile` المرفق). اضبط نفس متغيرات `.env` في لوحة الاستضافة، واضبط `BASE_URL` على عنوان موقعك **بـ https** لأن روابط العملاء تُبنى منه. ملاحظة: الفيديوهات تمرّ عبر خادمك، فاختر استضافة بعرض نطاق مناسب.

## 3) بنية المجلدات في Drive

```
المشاريع/                    ← DRIVE_ROOT_FOLDER_ID
  مجمع الأمل/                ← مشروع
    cover.jpg                ← صورة الغلاف (اختياري)
    info_ar/  info_ku/  info_en/   ← المعلومات (عربي / كوردي / English)
    videos/   maps/   location/   prices/
```
- **أسهل طريقة**: من الموقع (حساب المسؤول) زر «مشروع جديد» ينشئ المجلدات تلقائياً، ثم «رفع ملفات» أو السحب والإفلات على أي قسم.
- أو من Drive مباشرة: أنشئ مجلد مشروع بالأسماء أعلاه وضع الملفات؛ تظهر خلال 30 ثانية (أو زر التحديث). هذا الأنسب للفيديوهات الكبيرة.
- «إضافة رابط» تضيف روابط (يوتيوب، موقع خرائط Google) بدل ملفات.
- الحذف من الموقع ينقل إلى سلة Drive ويمكن استرجاعه.

## 4) الإدارة

لوحة الإدارة (للمسؤول): إضافة موظفين، إيقاف/تفعيل الحساب فوراً، كلمة مرور جديدة، تغيير الصلاحية، وتعديل اسم الموقع وأسماء الأقسام ومفتاح الدولة (964) وجملة بداية رسالة واتساب (`{project}` = اسم المشروع).
تسجيل الدخول يبقى محفوظاً على جهاز الموظف سنة كاملة.

## 5) كيف يعمل واتساب

- كل زر «إرسال» يفتح واتساب برسالة جاهزة تحوي **رابط الملف**. العميل يضغط الرابط فيفتح/ينزّل الملف دون تسجيل دخول.
- حقل «رقم العميل» أعلى الصفحة (اختياري): إن كتبته تُفتح المحادثة معه مباشرة، وإلا تختار جهة الاتصال من واتساب.
- زر القسم/المشروع يرسل كل الروابط في رسالة واحدة؛ وإذا كثرت يرسل رابط صفحة مرتبة للعميل.
- إرسال الملف نفسه كمرفق غير ممكن عبر روابط واتساب العادية (يتطلب WhatsApp Business API المدفوع).
- الروابط الموقّعة لا تكشف بقية Drive. لإبطال كل الروابط المرسلة سابقاً غيّر `SESSION_SECRET`.
